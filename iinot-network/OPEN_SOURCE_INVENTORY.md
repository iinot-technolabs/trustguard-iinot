# Open-source components

The authoritative register of open-source software and licences for TrustGuard IIoT — every component,
its exact version, licence, where it is used and any modifications — is **document 09, "Open-source
Software & Licence Register"**, in the submission. This file used to hold an earlier list (June 2026) that is
now out of date and was removed so that only one register exists.

Quick reference for this repository: Hyperledger Fabric 2.5.15 and Fabric CA 1.5.17 (Apache-2.0); Node.js
packages listed with versions in each `package-lock.json`; `iinot-network/core.yaml` is the Fabric 2.5.15
sample `core.yaml` (Apache-2.0, notice kept) with one changed line (`vm.endpoint`).
